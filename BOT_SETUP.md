# Bot Logo & Description Setup

## Set Bot Description

1. Open Telegram
2. Search for **@BotFather**
3. Send: `/setdescription`
4. Select your bot: **@SHIBA2BOT**
5. Send this description:
   ```
   SHIB2BOT is here to rebuild ShibArmy ecosystem. Stealth launch - fair for everyone! Generate AI videos with /video command.
   ```
6. BotFather will confirm the description is set

## Set Bot About Text

1. In BotFather, send: `/setabouttext`
2. Select your bot: **@SHIBA2BOT**
3. Send:
   ```
   Rebuilding ShibArmy ecosystem with AI video generation. Stealth launch - fair for everyone! 🐕🚀
   ```

## Add Bot Logo/Avatar

1. In BotFather, send: `/setuserpic`
2. Select your bot: **@SHIBA2BOT**
3. BotFather will ask you to send a photo
4. **Send your logo image** (must be square, recommended: 512x512px)
5. BotFather will confirm the avatar is set

## Set Bot Commands Menu

1. In BotFather, send: `/setcommands`
2. Select your bot: **@SHIBA2BOT**
3. Send:
   ```
   start - Welcome message and instructions
   video - Generate AI video from text prompt
   ```

## Bot Settings Summary

After setup, your bot will have:
- ✅ Custom description
- ✅ About text
- ✅ Logo/avatar
- ✅ Command menu
- ✅ Welcome message with ShibArmy branding

## Quick Commands Reference

- `/setdescription` - Set bot description
- `/setabouttext` - Set about text
- `/setuserpic` - Set bot avatar/logo
- `/setcommands` - Set command menu
- `/mybots` - View all your bots
